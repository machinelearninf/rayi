# 🎂 Happy Birthday Rayi Rizkia — Digital Scrapbook Journal (22 Tahun)

Website jurnal scrapbook romantis dari **Keisya** untuk **Rayi Rizkia** (28 Oktober 2004 — 22 Tahun).

---

## 🚀 Cara Menjalankan

Kamu bisa menjalankannya dengan **2 cara mudah**:

### Cara 1: Menggunakan NPM (Vite)
Buka terminal di folder ini (`c:\LARAGON\www\rayi`), lalu ketik:
```bash
npm run dev
```
Website akan otomatis terbuka di browser di `http://localhost:3000`.

### Cara 2: Menggunakan Laragon
Cukup buka Laragon, klik **Start All**, lalu buka browser di:
`http://localhost/rayi` atau `http://rayi.test`
